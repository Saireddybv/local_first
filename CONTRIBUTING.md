# Contributing

Keep changes focused on reliable local tools with explicit device permissions. Open an issue describing the real problem, reproduction steps, expected behavior and Windows/iOS versions. Never attach private files, clipboard contents, pairing links or session cookies.

Use a feature branch and a small pull request. Add meaningful regression coverage for behavioral changes. Run `python -m pytest`, then the relevant manual checks in `docs/testing.md`. Explain behavior, validation and limitations in the PR. Avoid external runtime assets and telemetry. New features need evidence from the problem log.
